# reaction-test.org

Single-page reaction time test built with Next.js 14, TypeScript, and Tailwind CSS.

## Local development

```powershell
npm.cmd install
npm.cmd run dev
```

## Verification

```powershell
npm.cmd run test
npm.cmd run build
```
